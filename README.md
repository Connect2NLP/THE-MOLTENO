# The Molteno — Website Rebuild

New look and feel for www.themolteno.com. Static HTML/CSS/JS, no build step.

## Structure
- `index.html` — homepage (story, rooms, reviews, experiences, FAQ)
- `rooms-rates.html` — full rooms & rates listing
- `contact.html` — contact page + form
- `css/styles.css` — design system (colors, type, components)
- `js/main.js` — header scroll behavior
- `assets/logo/` — brand logo (kept from original site)
- `assets/images/` — room photography (kept from original site)

## Status
Logo, room images, and rates are carried over from the live site. The
hero section on the homepage is a placeholder built on the new design
system — final hero content/imagery is still to come.

## Running locally
Just open `index.html` in a browser, or serve the folder with any static
file server.
